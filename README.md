# Snudhana Portfolio

Personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS. The original dark color palette, Lato typography, and page layout are preserved; company logos use a pixelated rendering.

## Sections

- Experience
- Projects
- Tech Stack
- Contact

## Development

```bash
bun install
bun run dev
```

Create a production build with `bun run build`.
